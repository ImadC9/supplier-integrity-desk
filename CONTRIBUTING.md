# Contributing

Thanks for helping! Bug reports, new ERP column synonyms, quality rules and
matching improvements are all welcome.

## Set up

```bash
git clone https://github.com/ImadC9/supplier-integrity-desk
cd supplier-integrity-desk
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e ".[all,dev]"
supplier-desk app
```

## Before opening a pull request

```bash
python -m unittest discover -s tests -v
ruff check . && ruff format --check .
```

Tests must not need API keys, network access, model downloads or real data:
inject fake providers and fixed vectors (see `tests/test_analysis.py` and
`tests/test_policy_rag.py`).

## Ground rules

- **Never commit real supplier data**, tax IDs, bank details, credentials,
  review databases or generated outputs. Use the sample workbook or small
  made-up fixtures.
- Business logic lives in `supplier_agent/`; `supplier_agent/app.py` only presents it.
- A new quality rule needs a stable code, a priority, a plain-language summary,
  a suggested action, an entry in `RULE_DESCRIPTIONS` and a test.
- A matching change needs tests with **hard negatives** (similar names that are
  different companies) as well as true duplicates, and a re-run of
  `supplier-desk evaluate`.
- New ERP header names go in `supplier_agent/columns.py` with a mapping test.
- The sample workbook and example CSV are generated by `scripts/generate_sample_data.py`;
  change the script and regenerate rather than editing the files by hand.
- Keep the safety boundary: the source file is read-only, the agent uses only
  the allow-listed tools, raw identifiers never reach an LLM prompt, labels stay
  out of investigations, and a human makes every decision.

## Good first contributions

- Column synonyms for another ERP (Oracle, Dynamics, NetSuite, Odoo…)
- Country-specific tax-ID format checks as opt-in quality rules
- Hard-negative examples for the sample data
- Translations: copy `supplier_agent/i18n_es.py` for a new language
- Tax ID rules for more countries in `supplier_agent/taxid.py`
